S'more 'N More

This mod is my entry for a Minecraft ModJam. It adds different kinds of s'mores that each give the player a certain buff or effect.


Current features

- Custom ingredients that can be crafted from vanilla items.
- Roasting Marshmallows on a campfire.
- A classic normal s'more.

Future features

- Many different s'more flavors that will give special effects to the player. 
- Marshmallow block???

Recipes

Crafting recipes can be found [here](https://github.com/W-ADEMA/Smore_N_More/wiki/Recipes).


Requirements

- Minecraft 26.1.2
- NeoForge mod loaded (tested with version 26.1.2.112)
